Grok / xAI (primary)

Preferred path: official API at api.x.ai. On any failure (rate limit, 404, network), the extension tries X session cookies next, then OpenAI.

OpenAI (automatic fallback)

Used automatically whenever Grok (xAI API or X session) fails for any reason — including the common “session API unavailable (404)”. Recommended for reliability. Default model gpt-4o-mini is the freest widely available OpenAI option for this workload. Key is encrypted in the vault.

Google Gemini (free LLM backend)

Free tier API via Google AI Studio (aistudio.google.com). Generous free rate limits for gemini-2.0-flash and gemini-1.5-flash. Key is stored encrypted in your vault.

Microsoft / GitHub Models (free LLM backend)

Free LLM access via GitHub Personal Access Token or Azure OpenAI key. GitHub Models provides free tier access to gpt-4o-mini, Phi-4, and more (github.com/marketplace/models). Key is stored encrypted in your vault.

X / Twitter account pool

Grok session fallback when the xAI API is unavailable. Each account is uniquely keyed by @username (resolved via verify_credentials). Re-importing the same user updates cookies in place — no duplicates. Cookies are encrypted at rest.
